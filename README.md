# Primorial–Feedback Bridge

Reference Python implementation and automated numerical verification suite for:

> **Benjamin Edward Gray (2026).** *The Primorial–Feedback Bridge: Super-Gaussian Resolvent Lifting, Spectral Counting, and Fredholm-Module Compression for the Primorial-Modulated Dilation Operator.*

This repository couples the variable-exponent feedback operators $`\hat{\Omega}_G`$ and $`\hat{\Omega}_G^{\mathrm{odd}}`$ (generated by $`f(x) = x^{1/x - 1}`$) to the primorial-modulated dilation operator $`D_k = D_{0,k} \otimes I + \varepsilon_0 I \otimes T_k^{\mathrm{Herm}}`$ on $`\mathcal{H}_k = L^2(\mathbb{T}_{L_k}) \otimes \mathbb{C}^{N_k}`$.

## Module Map

| Module | Paper Section | Core Results Verified |
| --- | --- | --- |
| `feedback.py` | Sec. II.A | Scalar maps $f, f_{\mathrm{odd}}$, constants $x_{\max}, x_{\mathrm{crit}}, \delta$, and matrix functional calculus $\hat{\Omega}_G, \hat{\Omega}_G^{\mathrm{odd}}$ |
| `primorial.py` | Sec. II.B | Prime channels $`\tilde{C}_p`$, $`T_k^{\mathrm{Herm}}`$, $`k`$-qubit Kronecker block $`V_{\chi_0}`$, unit-group permutations $`U_g`$ |
| `fiber_gating.py` | Sec. III (Thm 3.1–3.2) | Prime-channel fixed points, Daleckii–Krein derivative, $U_g$ intertwining, basin partitions (Tables 1–2) |
| `resolvent_counting.py` | Sec. IV (Thm 4.1–4.2) | Super-Gaussian lift $(I + \tau D_k^2)^{-\tau D_k^2}$ and trace-norm spectral counting $N_{D_k}(\tau^{-1/2})$ (Table 3) |
| `fredholm.py` | Sec. V (Thm 5.1) | Doubly-exponential Schatten acceleration $2^{n+1}$, defect convergence, finite-rank commutator compression |
| `synthesis_obstructions.py` | Sec. VI (Prop 6.1, Cor 6.2) | Closed-form $`\exp(\alpha \tilde{C}_p)`$, 4th-order BCH entry, $`V_{\chi_0}`$ rigidity, 1D gauge equivalence & Wilson loop (Table 4) |
