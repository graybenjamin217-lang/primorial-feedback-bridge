# Primorial–Feedback Bridge

Reference Python implementation and automated numerical verification suite for:

> **Benjamin Edward Gray (2026).** *The Primorial–Feedback Bridge: Super-Gaussian Resolvent Lifting, Spectral Counting, and Fredholm-Module Compression for the Primorial-Modulated Dilation Operator.*

This repository couples the variable-exponent feedback operators $\hat{\Omega}_G$ and $\hat{\Omega}_G^{\mathrm{odd}}$ (generated by $f(x) = x^{1/x - 1}$) to the primorial-modulated dilation operator $D_k = D_{0,k} \otimes I + \varepsilon_0 I \otimes T_k^{\mathrm{Herm}}$ on $\mathcal{H}_k = L^2(\mathbb{T}_{L_k}) \otimes \mathbb{C}^{N_k}$.
